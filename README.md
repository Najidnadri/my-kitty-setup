# my-kitty-setup

My [kitty](https://sw.kovidgoyal.net/kitty/) terminal config: Catppuccin Mocha colours, JetBrainsMono Nerd Font, and gnome-terminal-style keybindings.

## Install

```sh
git clone https://github.com/Najidnadri/my-kitty-setup.git ~/.config/kitty
```

Requires the JetBrainsMono Nerd Font to be installed.
